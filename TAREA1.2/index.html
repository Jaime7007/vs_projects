Etiquetas de autocierre by Jaime

Etiqueta br

La etiqueta <br> sirve para insertar un salto de línea dentro de un bloque de texto.

Ejemplo: Esta es la primera línea.
Esta es la segunda línea después del br.

Etiqueta hr

La etiqueta <hr> crea una línea horizontal que separa secciones de contenido.

Ejemplo:

Contenido arriba de la línea.

Contenido abajo de la línea.

Etiqueta img

La etiqueta <img> muestra una imagen guardada en la carpeta del proyecto.

Etiqueta input

La etiqueta <input> se utiliza para crear un campo de entrada interactivo en un formulario donde el usuario puede introducir datos.

Etiqueta col

La etiqueta <col> define las propiedades de una columna dentro de una tabla.

Columna 1 Columna 2
Dato A Dato B

Etiqueta embed

La etiqueta <embed> incrusta un recurso o contenido externo interactivo en la página web.
