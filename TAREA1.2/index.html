Etiquetas de autocierre by Jaime

Etiqueta br

La etiqueta <br> sirve para insertar un salto de línea dentro de un bloque de texto.

Ejemplo: Esta es la primera línea.
Esta es la segunda línea después del br.

Etiqueta hr

La etiqueta <hr> crea una línea horizontal que separa secciones de contenido.

Ejemplo:

Contenido arriba de la línea.

Contenido abajo de la línea.

Etiqueta img

La etiqueta <img> muestra una imagen guardada en la carpeta del proyecto.

Etiqueta input

La etiqueta <input> se utiliza para crear un campo de entrada interactivo en un formulario donde el usuario puede introducir datos.

Etiqueta col

La etiqueta <col> define las propiedades de una columna dentro de una tabla.

Columna 1 Columna 2
Dato A Dato B

Etiqueta embed

La etiqueta <embed> incrusta un recurso o contenido externo interactivo en la página web.

Etiqueta param

La etiqueta <param> va dentro de un elemento <object> y se utilizaba históricamente para pasar parámetros de configuración a complementos o applets (como Adobe Flash Player).

Actualmente esta etiqueta está obsoleta en HTML5. Aunque el elemento <object> se utilice para cargar un recurso externo, la etiqueta <param> es ignorada por el navegador y no genera ningún efecto visible porque los navegadores modernos han eliminado el soporte para plugins de terceros y no procesan este tipo de parámetros.

Etiqueta source

La etiqueta <video> permite reproducir archivos de vídeo. Al incluir varias etiquetas <source>, el navegador elige el primer formato compatible.

La etiqueta <audio> funciona igual para archivos de sonido, ofreciendo alternativas de formato mediante <source>.

Etiqueta wbr

La etiqueta <wbr> indica un lugar donde el navegador tiene permiso para dividir una palabra mediante un salto de línea si la pantalla es muy estrecha.

Ejemplo: SupercalifragilisticoespialidosoConUnSaltoDeLineaOpcional
