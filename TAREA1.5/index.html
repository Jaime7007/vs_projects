Qué son los elementos semánticos

A diferencia de los elementos neutros como div o span, los elementos semánticos aportan significado al contenido tanto para los navegadores como para los motores de búsqueda y tecnologías de asistencia.

Cada etiqueta tiene una función clara: header para la cabecera, nav para la navegación, main para el contenido principal, section para agrupaciones temáticas, article para contenido independiente, aside para información complementaria y footer para el pie de página.
